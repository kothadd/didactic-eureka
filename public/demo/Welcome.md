# Welcome to the Public collection

This is a working sample collection for Degoo Index.
These are generated demo files, not files from a connected Degoo account.

## Try it out

- Open Documents → Guides to explore nested folders.
- Search for a filename from Public to include every subfolder.
- Select files or folders, then prepare a recursive download list.
- Open the image and audio samples for a native browser preview.

## Live access

The live adapter stays locked until a local compatibility check confirms
folder listing and a known file download. Read README.md for setup.

Public access is read-only. Account credentials never belong in the browser.
